### QI-201 help vs CLI.md
positional arguments:
  <command>
    query               Ask a question and print the rows.
    register            Register a continuous query. It runs until dropped.
    queries             List the continuous queries the node runs.
    pause               Stop a query without releasing it; its view keeps
                        answering.
    resume              Start a paused query again.
    drop                Remove a query's name; the computation goes with its
                        last name.
    replace             Start a blue/green replacement of a running query.
    replacements        How replacements are getting on.
    cutover             Move the name to the new version.
    rollback            Put the replaced version back while it is retained.
    abandon             End a replacement that has not cut over.
    finish              Confirm a cutover: the replaced version is released;
                        no rollback after.
    throttle            Set the backfill's rate, up to its ceiling.
    pause-backfill      Stop the backfill reading, keeping what it has read.
    resume-backfill     Start the backfill reading again.
    subscribe           Print a view's committed changes as they happen.
    dlq                 Dead letters: the records a query's feed could not
                        decode.
    debug               Fork a query from a checkpoint and step it (ADR-048).
    status              The node: version, engine state, plugins.
    health              The node's health; exit 1 unless UP or DEGRADED.
    version             The CLI's version and the node's.
    metrics             The node's Prometheus metrics, raw.
    plugins             Every plugin the node can load.
    sinks               The sinks the node binds.
    streams             List, describe or declare streams.
    views               List views, or describe one.
    describe            One registered query in full, including its lane.
    plan                The plan a registered query runs, with operator
                        metrics.
    validate            Plan SQL against the node without running it.
    explain             The plan the node would run for SQL.
    run                 Offline: moved to `pravaha-engine run`.
    lanes               Where every query runs, and an administrator's
                        rebalance.
    audit               The node's recorded authorization decisions, newest
                        first.
    tenants             Admission quotas and each tenant's use.
    permissions         What this principal may do.
    login               Sign in and print (or --save) a session token.
    logout              End this session and delete the saved token.
    whoami              Who the engine says you are.
    password            Change your password, or redeem a reset token.
    user                Administer users (admin role).
    key                 API keys: shown once, scoped to a subset of your
                        roles.
    session             Sessions: yours, or everyone's (admin).
    ask                 Draft a continuous query from a description (asks a
                        model; the engine judges it).
    explain-sql         A query in plain English, grounded in the engine's
                        plan (asks a model).
    why                 What a refusal means and what to change (asks a model;
                        the engine checks any rewrite).
    assist              The assistant's models, profiles and providers.
    catalog             The catalogue: objects, namespaces, owners, tags.
    grant               Grant privileges on an object to a role or user
                        (MANAGE).
    revoke              Revoke privileges on an object from a role or user
                        (MANAGE).
    grants              Grants on an object, or to a role or user.
    access              Why a user may (or may not) do something to an object.
    policy              Row filters and column masks: define, bind, unbind,
                        drop.
    alerts              Alerts: what is firing, and pause, snooze or
                        acknowledge one.
    alert               Create or drop an alert (a CREATE ALERT statement,
                        over Flight).
