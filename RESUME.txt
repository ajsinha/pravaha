  (refusePartitionedServing, PRV-9002): the factory still builds the

  ownership gate in PartitionedIngestPump that DROPS rows this node cannot
  prove it owns. Review the design before using it: dropping is only safe if
  another node reads the same source and keeps the row; otherwise, once the
  offset moves past it, the row is lost.

4. HOUSE RULES
====================================================================

  * Ashutosh Sinha is the sole author of every commit, and a commit
    message ends with its own text: no trailers of any kind. Absolute.
  * git add with EXPLICIT PATHS. Never git add -A.
  * Verify, THEN commit, THEN push. "Drill to develop" = commit and push
    develop. "Drill to main" = merge develop into main and push main. A bare
    "drill" = both. Work happens on develop; main moves only on a drill.
  * docs/qa/FINDINGS.md is owned by the lead session. Agents never edit it.
  * Documentation rot is a build failure. After doc edits:
        ./mvnw -o -pl pravaha-it test \
          -Dtest='DocumentationFreshnessTest,FindingsRegisterTest' \
          -DfailIfNoSpecifiedTests=false
  * NEVER report a build as passing without checking. Grep for BUILD SUCCESS
    and BUILD FAILURE separately and report both counts. A run with
    -Dmaven.test.failure.ignore prints BUILD SUCCESS over failing tests.
  * Do NOT run two Maven builds in the same checkout at once.
  * Avoid SQL reserved words as test view names: second, large, and friends
    are refused with PRV-8008.

  Console:  (cd console && JAVA_HOME=... make test), after
      ./mvnw -o -pl pravaha-flight -am test-compile
